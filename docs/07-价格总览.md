## 2. 三档配置的月成本估算

**场景假设**：1 个人起步，每月找 ~500 家公司、发 ~2000 封开发信。

### 🆓 全免费栈 —— **约 $0–1/月**

| 项 | 成本 |
|---|---|
| Ollama 大模型 | $0（电费） |
| SearXNG 找客户 | $0 |
| 抓官网挖邮箱 | $0 |
| 本地 MX 验证 | $0 |
| 发信 | 不真发（人工复制发）或 Brevo 免费 300/天 |
| 域名（若真发） | ~$1/月 |
| **合计** | **$0–1/月** |

先零成本验证"找客户+AI写信"效果，有效果再花钱。

### 💵 够用版 —— **约 $80–130/月**（首月含 Serper $50 够用半年）

| 项 | 成本 |
|---|---|
| DeepSeek 大模型 | ~$5/月 |
| Serper 找客户 | $50/5万次（够用 ~半年 → 摊 ~$8/月） |
| Hunter Starter 挖邮箱 | $34/月（2000 额度） |
| ZeroBounce 验证 | $39/2000 条（或先用免费 100） |
| SES 发信 + 域名 | ~$1.2/月 |
| **合计** | **首月 ~$130，之后 ~$80/月** |

| 项 | 成本 |

## 3. 关键结论

1. **第一个月几乎可以 $0 起步**：Ollama/SearXNG/抓官网/本地验证全免费，各付费服务还都送免费额度
   （Serper 2500 次、Hunter 50/月、ZeroBounce 100/月、Apollo Free 档、DeepSeek 500 万 token、SES 前 12 月 3000 封）。
2. **成本大头是"数据"（找客户+挖邮箱），不是 AI 或发信**。AI 写信、SES 发信都便宜到可忽略。
3. **省钱的正确顺序**：免费栈验证效果 → 够用版小规模真跑 → 旗舰版放量。别一上来买一堆。
4. **价格随用量走**：上面按"1 人 ~2000 封/月"估。真正贵的是数据额度（Apollo/Hunter credit），
   量大时按"每找到一个有效客户的成本"来算 ROI（行业每个合格会议成本 $150–600，空间很大）。
