# 06 上线接入指南：从"演示"到"真实可用"

> 回答一个问题：**要把这套系统变成"真的能找到客户、真的能发出邮件"，需要接入哪些东西？**
> 以及：**怎么把 Mac mini 当云服务器用。**

---

## 0. 先认清现状（重要，别被"切个开关就行"误导）

系统默认 `ADAPTER_MODE=local`，所有外部能力用内置"假适配器"（零费用、不真发邮件），
用来验证产品与流程。要"真实可用"，需要**接入真实供应商的账号和密钥**，并把 `ADAPTER_MODE=cloud`。

真实适配器的实现状态：

| 能力 | 真实适配器 | 状态 | 需要你提供 |
|---|---|---|---|
| 大模型（背调/写信/分类） | DeepSeek / 通义千问（OpenAI 兼容） | ✅ 已实现 | API Key |
| 找客户（搜索源） | Serper.dev（Google 搜索） | ✅ 已实现 | API Key |
| 挖邮箱（富化） | Hunter.io | ✅ 已实现 | API Key |
| 验证邮箱 | ZeroBounce | ✅ 已实现 | API Key |
| 发邮件 | Amazon SES | ✅ 已实现 | AWS 账号 + 发信域名 |
| 海关数据（最强外贸源） | ImportGenius / 腾道 | ⏳ 留了接口，待接入 | 商业数据合同 |
| 谷歌地图找客户 | Outscraper / Apify | ⏳ 留了接口，待接入 | API Key |

**结论**：上面 5 个"✅ 已实现"的，你只要注册账号、把 Key 填进 `.env`，就能真实跑通
"找客户 → 挖邮箱 → 验证 → AI 写信 → 发送"。海关/地图两个源要接的话，按
`docs/05` 第 3 节实现对应端口即可（业务代码不用动）。

> 顺序建议：①→②→③→④ 半小时内可全部注册完（都支持自助+支付宝/信用卡），当天就能跑「找客户+AI写信」；⑤ AWS 的生产访问审核需 1–2 天，尽早提交。

按这 5 步注册并填 Key，就能真实发第一封信。`.env` 变量名见括号。

### ① 大模型 —— DeepSeek（最便宜）或通义千问 Qwen
- 注册 https://platform.deepseek.com → 拿 API Key
- 填：`LLM_BASE_URL=https://api.deepseek.com/v1`、`LLM_API_KEY=sk-...`、
  `LLM_MODEL_WRITER=deepseek-chat`、`LLM_MODEL_CLASSIFIER=deepseek-chat`
- 成本：极低，百万 token 几块钱人民币量级。写一封信/做一次背调都是几分钱。

### ② 找客户 —— Serper.dev（Google 搜索 API）
- 注册 https://serper.dev → 拿 API Key（有免费额度）
- 填：`SERP_API_KEY=...`
- 成本：约 $50 / 5 万次查询量级。一次"找客户"约消耗 1 次查询。

### ③ 挖邮箱 —— Hunter.io
- 注册 https://hunter.io → API Key
- 填：`HUNTER_API_KEY=...`
- 成本：$34/月起（按 credit）。一个域名查一次约 1 credit。

### ④ 验证邮箱 —— ZeroBounce
- 注册 https://zerobounce.net → API Key
- 填：`EMAIL_VERIFY_API_KEY=...`
- 成本：$16 起（按条），约 $0.008/条。**这步省不得**——不验证直接发会毁域名信誉。

### ⑤ 发邮件 —— Amazon SES + 一个发信域名（关键，最需要耐心）
- 注册 AWS → 开通 SES → 申请"生产访问"（脱离沙箱，审核 1–2 天）
- **单独买一个发信域名**（别用你的主域名！如主站是 `abc.com`，买 `abc-mail.com` 或 `getabc.com`）
- 在 SES 里验证该域名，按提示给域名配 **SPF / DKIM / DMARC** 三条 DNS 记录
- 填：`AWS_REGION`、`AWS_ACCESS_KEY_ID`、`AWS_SECRET_ACCESS_KEY`、`SES_CONFIGURATION_SET`
- 装依赖：`cd services/api && uv sync --extra cloud`（装 boto3）
- 成本：SES 约 $0.10/千封，几乎可忽略；域名约 $10/年。

> 五项起步月成本大概 **$100–150 + 少量用量**，就能真实跑起一个人的外贸获客。

## 2. 三条不能踩的红线（决定成败）

1. **绝不用 Mac mini 的家庭宽带 IP 直接发冷邮件**。住宅 IP 发外联邮件 = 秒进垃圾箱 / 被封。
   发信**必须走 SES**（专业发信 IP 池）。Mac mini 负责跑应用、找客户、AI，**发信外包给 SES**——
   系统架构已经是这么设计的，你只要接 SES 即可。
2. **新发信域名必须预热 2–4 周**，从每天几封慢慢加量。系统内置了预热状态机与频控，
   注册发信域名/邮箱后它会自动按阶段限量——别手动绕过。
3. **只发企业邮箱、带一键退订、退订即抑制**。这些系统已强制（个人邮箱直接拒发）。
   别导入买来的名单猛发，那是自毁。

## 3. 把 Mac mini 当云服务器：网络与常驻

Mac mini 跑应用没问题（找客户、AI、CRM、看板都在本机；发信走 SES）。要让它"像云服务器"被外部访问：

### 让外网能访问（推荐 Cloudflare Tunnel）
最省事、免费、自带 HTTPS、**不需要公网 IP、不用在路由器上开端口**：
```bash
brew install cloudflared
cloudflared tunnel login
cloudflared tunnel --url http://localhost:3000   # 前端
# 生产建议建命名隧道，把 你的域名 → localhost:3000/8000 固定映射
```
替代方案：路由器端口转发 + 动态域名(DDNS)，但要处理公网 IP 变动与 HTTPS 证书，较麻烦。

### 开机自启 / 常驻
- 用 Docker：`docker compose up -d`（`docker-compose.prod.yml` 已设 `restart: unless-stopped`，
  Mac 重启后自动拉起）。Docker Desktop 设为登录时启动。
- 或用 macOS `launchd` 写一个 plist 守护 `mac-quickstart.sh`。

### 数据库
起步用 SQLite（零配置）或本机 Postgres（docker）都行。数据量上来后再迁云托管 Postgres。
**每天备份 `suppression_entries`（抑制列表）**——这是最不能丢的数据。

## 4. 从演示切到真实：操作顺序

```bash
# 1. 编辑 .env
ADAPTER_MODE=cloud
#   填入上面 ①~⑤ 的所有 Key

# 2. 装云端依赖（boto3）
cd services/api && uv sync --extra cloud

# 3. 起服务（Mac mini 上用 docker compose up -d 常驻）

# 4. 在系统里注册发信域名与邮箱（会自动进入预热）
curl -X POST localhost:8000/api/sending/domains \
  -d '{"domain":"getabc.com","spf_ok":true,"dkim_ok":true,"dmarc_ok":true}'
curl -X POST localhost:8000/api/sending/mailboxes \
  -d '{"sender_domain_id":"<上一步返回的id>","email":"jane@getabc.com"}'

# 5. 跑真实闭环：找客户 → AI 备信 → 人审 → 发送
#    前端点几下即可，或走 /api/leads/discover → /orchestration/campaigns/{id}/prepare
#    → 人审通过 → /orchestration/campaigns/{id}/launch → /orchestration/tick
```

## 5. 稳妥的上线节奏（建议）

1. **第 1 周：只开"找客户 + AI 背调 + AI 写信"，先不真发**。人工看 AI 找的客户准不准、
   写的信好不好。这步只需 ①②③④（不需要 SES），成本最低，先验证质量。
2. **第 2–4 周：接 SES + 发信域名，开始预热**（系统自动小量发）。同时人工审每封 AI 草稿
   （人审队列），积累"批准率"。
3. **之后：批准率稳定后，逐步对模板放开自动发送**；接海关数据源提升找客户精度；
   量大了再把数据库/发信迁到云。

## 6. 如果要接"海关数据"（外贸最强源）

海关数据能直接看到"谁在进口什么、量多大"，是外贸获客王牌，但需要商业合同：
- 国际：ImportGenius（自助订阅，美线较友好）、Panjiva（企业级）
- 国内：腾道 Tendata、特易资讯（覆盖多国）
接入方式：在 `services/api/app/adapters/real/data_sources.py` 里按 `DataSourcePort`
写一个 `CustomsSource` 类（`search()` 调其 API、把进口商映射成 `CompanyCandidate`，
把采购记录塞进 `raw["customs"]`——评分逻辑已会据此加分），然后加进
`build_real_data_sources()` 的返回元组。**业务与前端一行都不用改。**
