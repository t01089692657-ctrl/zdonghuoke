## 1. 对标产品：麦穗获客 / 麦穗智能体全拆解

### 1.1 基本盘

| 项 | 内容 |
|---|---|
| 定位 | 面向中国外贸出口企业的 AI 主动营销获客系统，覆盖"客户资源获取 → 客户开发触达 → 客户运营成交 → 客户管理沉淀"全流程 |
| 口号 | "外贸 AI 获客，外贸精准客户联系人，海关数据"；麦穗智能体："您的全时段外贸业务员 / 7×24 小时外聘业务员" |
| 目标客户 | 依赖主动开发的中小外贸企业、工厂外贸部、外贸 SOHO；官方称服务国内近 9000 家 + 海外近 2000 家企业，覆盖 100–150+ 行业 |
| 定价 | **29,800 元/年**（全国统一报价，代理商渠道分销），有免费体验入口 |
| 运营主体 | 上海珥文信息科技有限公司（研发中心在上海），全国代理商体系 |
| 产品演进 | 10 年 6 次革新：数据库建设 → 全渠道资源整合 → 自动开发 → SOP 运营自动化 → AI 深度应用 → AI 智能体营销 |

### 1.2 四大业务模块与功能清单

麦穗把系统分为**客户资源、客户开发、客户运营、客户管理**四大模块：

**（A）客户资源（"十大采购商源头"）**

| # | 数据源 | 说明 |
|---|---|---|
| 1 | 搜索引擎 | Google/Yahoo/Bing + 各国黄页 + 垂直 B2B 站，按关键词/HS 编码/公司名搜采购商 |
| 2 | 海关数据 | 2018 年至今、约 160 国提单/报关数据；买家"贸易趋势、贸易国、贸易伙伴、贸易产品"四维报表 |
| 3 | 社媒采购商库 | Facebook/LinkedIn/X/Instagram 企业主页采集清洗 |
| 4 | LBS 谷歌地图 | 按国家/城市/商圈"扫街式"找当地企业 |
| 5 | 展会资源 | 广交会等展会到会企业与买手名录 |
| 6 | 品牌商标库 | WIPO 全球品牌商标数据，用品牌反查采购商 |
| 7 | 海外 B2B 平台 | Europages、Thomasnet、B2B Brazil 等平台采购商 |
| 8 | 跨境电商小 B | 亚马逊等平台卖家数据 |
| 9 | B2B 询盘买家 | 海外 B2B 平台公开询盘采集（真实采购需求信号） |
| 10 | 麦穗搜吧/俄罗斯专区 | 碎片化大数据检索入口；独家俄罗斯工商数据（十大的第 10 项为推测拼合） |

**（B）联系人挖掘与背调**
- 邮箱、LinkedIn、电话**三重聚合查询**，直接给出关键决策人（KP）的职位与联系方式；
- **360 度买家背景**：公司概况、联系人、海关交易记录、社媒动态等 10 项数据聚合成"客户详情表"；
- **AI 背调**：10 秒–1 分钟生成《商业模式分析报告》（产品类型、应用领域、采购规律、现有/前供应商）；
- **AI 客户评分**：建档完善度、匹配度、活跃度、联系紧密度多维打分排序。

**（C）客户开发（触达工具矩阵）**

| 工具 | 说明 |
|---|---|
| 全自动开发 | 设定关键词+市场+画像后，全自动"搜客户→锁定 KP→提取邮箱→投递开发信"，每天最多触达 500 个买家 |
| 半自动开发 | 人工圈选资源，系统批量挖联系人并发信 |
| KP 直通车 | 指定公司直取决策人 LinkedIn+邮箱，双通道触达 |
| WhatsApp 直通车 | 挖掘买家 WhatsApp 号码并触达 |
| 同心圆/供应链 | 海关数据专用：沿贸易伙伴关系网/供应链上下游扩展相似买家（推测） |
| AI 智慧营销开发 | 自动拓词、生成多轮"连环开发信"计划、"千邮千面"、自动制定开发策略 |
| 发送基建 | 第三方海外邮件服务商 + 许可式批量投递 + 分布式发送 + 多 IP 轮换 |

**（D）客户运营（麦穗特色模块——SOP 自动化）**
- 把"对潜客的反复触达"做成 SOP：预设内容、时间间隔、判断标准、达成目标，系统自动执行；
- 内置 5–6 种 SOP：循环推广、事件推进、意向判断、节日问候、不间断联系等；
- **AI 运营计划**：按月递进生成不同阶段邮件并自动发送；
- **邮件探针 1.0/2.0**：打开次数/时间/地点监测；邮件内 CTA 意向按钮；个人产品库目录页；客户浏览/点击行为采集；
- 多邮箱 Web 客户端（IMAP，含 Gmail）；社媒排期发帖；素材中心（模板/签名/产品库）。

**（E）客户管理**
- 客户汇总（自有客户库）、客户阶段管理、跟进记录；
- **AI 建档（"价值判断"）**：AI 分析所有往来邮件，自动识别潜在客户并建档；
- **AI 推荐线索**：综合探针行为+关键词+匹配分推荐高价值采购商；
- 数据看板：送达/打开/点击/意向统计、同期比较。

### 1.3 麦穗智能体："五步法"AI 闭环

麦穗智能体宣称由自研"外贸大模型"驱动（推测为通用大模型微调/封装 + 行业知识库），配套企业知识库（先"学习"本公司与产品）。五步：

1. **分析市场**：输入产品自动锁定 HS 编码 → 中国出口市场分析报告（三年逐月同比）→ 目的国增长机会/下滑预警 → 新兴市场与跨界客群发现（"低竞争客户池"）；
2. **采集客户**：全供应链采购商画像（分销商画像 + OEM 贴牌商 + 终端用户画像），覆盖十大来源；每个买家自动 360 度背调 + 多通道联系方式 + AI 匹配度打分；
3. **开发跟进**：AI 自动制定开发策略与节奏，生成递进式连环开发信序列，结合探针数据判断意向并调整跟进；
4. **撰写邮件**：按行业特征、产品特点、地理位置、联系人职位等多维参数个性化生成，"千邮千面"，30 秒出信；
5. **AI 社媒 + AI 建档**：自动生成社媒内容并排期发帖（发信+种草组合）；AI 分析往来邮件自动归档潜客。

交互层有 **AI 助理**（快捷指令建任务、建档提醒、社媒设置、对话问答）。

### 1.4 麦穗的差异化主张与短板（我们的机会）

**长处**：数据源广度（十大源头）、SOP 客户运营模块独有定位、三重聚合联系方式、五步法全漏斗自动化、"软件+陪跑"交付体系。

**可攻击的短板**（结合第三方用户反馈与行业对比）：
- 报价制+全国统一 29,800/年，无自助低价档，1–5 人小团队被挡在门外；
- 无公开的送达率基础设施概念（预热、域名池、信誉监控），用户反馈"EDM 要坚持发才见效"暗示送达质量粗放；
- 数据是"库存式"的自有数据库，缺少 Clay 式实时研究智能体与多源交叉验证；
- 无透明的效果指标体系（回复率/订会率），交付依赖人工陪跑。

### 2.2 通用功能矩阵（加粗 = 头部产品必备项）

1. **线索发现**：**企业/联系人多维搜索**、**海关数据**、地图获客、搜索引擎/黄页采集、社媒源、**相似客户推荐（Lookalike）**、意向信号（招聘/融资/换岗/网站访客）、供应链图谱（OKKI AiReach 特有）；
2. **联系方式挖掘**：**邮箱查找+验证**、电话挖掘、**KP 识别**、社媒账号关联、瀑布流多供应商富化（Clay 首创）、查重/撞单/防飞单（中国特色刚需）；
3. **触达自动化**：**冷邮件多步序列**、**送达率基建（预热/三件套/黑名单监控/多邮箱轮换）**、**多渠道序列（邮件+LinkedIn+WhatsApp+电话）**、**统一收件箱**、会议排程；
4. **AI 能力**：**AI 写信/多语言/润色**、AI 研究智能体（Claygent）、AI 评分推荐、AI 回复分类与自动应答、AI SDR 闭环（OKKI AiReach、Instantly Agents）、垂直大模型（特易 TradeGPT、麦穗外贸大模型）；
5. **CRM**：轻 CRM、客户 360 视图、团队协同/公海、主流 CRM 双向同步；
6. **分析看板**：campaign 漏斗、渠道 ROI、送达健康度、市场情报；
7. **平台生态**：Chrome 插件、开放 API/Webhook、移动端、多工作区白标、积分/席位计费引擎；
8. **合规**：GDPR/CCPA 声明、Gmail/Yahoo 批量发件人新规（投诉<0.3%、退信<2%）、数据来源审计。

### 2.3 赛道趋势（2024–2026）

1. **"工具 → AI SDR 智能体"是最大主线**：AI SDR 市场 2025 年约 $41–44 亿，2030 年预计 $150 亿；产品叙事从"帮你找线索"转向"替你完成 SDR 工作"；
2. **规则序列 → 自主决策**：AI 自主决定联系谁/何时/哪个渠道/说什么，渠道自动切换成为新标配；
3. **质量优先取代数量轰炸**：2025 年 5 月起 Google/Yahoo/Microsoft 全面执行批量发件人规则，粗暴群发失效，送达率基建成为核心竞争力；
4. **实时研究智能体稀释静态数据库价值**："不再需要最大的库，而需要最会查的 Agent"；
5. **人机协同胜出，全自动 AI SDR 退潮**：行业共识是 AI 做调研/信号/草稿，人做判断/审批/真实互动；AI 辅助外联回复率约为传统 2 倍；
6. **商业模式向积分+结果漂移**：席位费之外，数据/AI 积分成主要变现杠杆，按会议/结果计费开始出现（<12% 厂商，增长中）。

## 4. 我们的差异化定位（结论）

在"复刻麦穗核心闭环"的基础上，选三个 2026 年被验证、且国内空白的差异点：

1. **多源瀑布流 + AI 实时研究背调（"外贸 Clay"）**：海关+地图+搜索+官网爬取+enrichment API 瀑布式交叉验证，AI 读买家官网/招聘/新闻做实时背调打分——打掉国内"数据源之争"，数据鲜度与覆盖率优于任何单库；
2. **送达率基础设施产品化**：域名池+邮箱池+自动预热+智能频控+信誉监控做成产品核心（国内同类无此概念，正被 Gmail 新规淘汰），"能到收件箱"是所有功能价值的前提，也是最深的护城河；
3. **人机协作 AI SDR（可解释、可审批）**：AI 找客/背调/写信/分诊回复，关键节点（首封信模板、意向回复）人工审批，每封 AI 信附"个性化证据"（引用了哪些真实字段），用批准率作为逐步放开自动化的闸门。

次级差异点（商业层）：透明定价 + 自助低价档（PLG）切入 1–5 人小团队长尾；合规作为卖点（数据来源可追溯、只打企业邮箱、自动退订）向上打中大客户。
